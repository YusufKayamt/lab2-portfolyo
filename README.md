## 📌 Proje Hakkında
Bu depo, modern web tasarım prensipleri (Design Tokens, CSS Grid/Flexbox, Mobile-First) kullanılarak sıfırdan geliştirilmiş **tam duyarlı (responsive)** kişisel portfolyo sitemin kaynak kodlarını içermektedir. Lighthouse testlerinden %100 erişilebilirlik (Accessibility) puanı almıştır.

## 💻 Öne Çıkan Geliştirmelerim
* 🛡️ **BlockSentinelAI:** CAN-Bus ağlarındaki siber saldırıları tespit etmeye yönelik yapay zeka entegrasyonlu yazılım projesi.
* 🌌 **DreamToon:** Kullanıcıların rüyalarını yapay zeka destekli animasyonlara dönüştüren web tabanlı uygulama.

## 🎨 Tasarım & Mimari
* **Mobile-First Yaklaşımı:** Tasarım önce dar ekranlar için kurgulanıp, `min-width` ile tablet ve masaüstü (`640px` ve `1024px`) cihazlara uyarlandı.
* **Design Tokens:** Renk paletleri, boşluklar (spacing) ve sıvı (fluid) tipografi CSS değişkenleri olarak `tokens.css` içinde merkezi olarak yönetildi.
* **Modern Layout:** Menü ve kart dizilimlerinde Flexbox ve akıllı Grid sistemleri (`auto-fit`) kullanıldı.
